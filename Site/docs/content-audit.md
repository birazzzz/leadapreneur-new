# Leadapreneur content audit

Audit date: 4 September 2026 (Asia/Kuala Lumpur context for event data)

## Sources used

- Current public homepage: positioning, client list, testimonial, organisation assessment, 80,000+, 250+, 5,000+, USD 120M+, current visible office address and social links.
- Current AI × Talent Accelerator page: CARES, Stratecution, project/value model, Greatness Games, COSMOS and progression language.
- Current projects page: project titles, themes, statuses, problems, solutions and published outcomes.
- Current case-studies page: DBS, UOB and OCBC results.
- Current insights index and article pages: titles, dates, authors and article themes.
- Current role quiz: three role names, descriptions, traits, images, questions and deterministic scoring behavior.
- Existing repository assets: client logos, team portraits and company photography.

## Resolved conflicts

### Role count

The implementation brief describes five roles, while the live quiz currently implements three: AI Explorer, AI Innovator and AI Vanguard. The website uses the three-role quiz taxonomy because it is the only complete, current system with approved questions, copy, scoring and role images. The older five-role progression is not presented as a personality quiz.

### Quiz privacy

The live event-oriented quiz asks for gender, name, email, phone, company and a photo before revealing a result. The redesign intentionally follows the brief's stricter privacy flow: landing → three questions → result. No personal data is requested, uploaded or stored remotely.

### Company impact totals

The current homepage and its metadata publish 80,000+ professionals and USD 120M+ in business impact. The About page still contains 60,000+ and USD 100M+. The redesign centralizes the newer homepage values and does not mix the two sets.

### Company address

The current visible homepage footer lists Level 7, Tower 7, Avenue 7, Menara Pernas, The Horizon, 59200 Bangsar South. Older Accelerator copy and the current Organization schema still list Wisma UOA Damansara II. The redesign uses the current visible homepage address.

### Events

Greatness Games KL Season 1 ran from 22 June to 3 July 2026 and is therefore presented as a past event. No future public event date was found, so the homepage and Events page use an intentional empty state rather than inventing an upcoming event.

## Content intentionally not fabricated

- No new client quote, partner logo, case-study outcome, project metric, speaker, capacity or future event date.
- No newsletter form because the working repository has no approved processing endpoint or consent flow.
- No contact form because the working repository has no approved processing endpoint or privacy behavior; contact uses the approved Calendly and WhatsApp paths.
